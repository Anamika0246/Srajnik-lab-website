## How to Get Your Own Images

### Method 1: Unsplash (Recommended)
1. Go to https://unsplash.com/
2. Search for an image (e.g., "technology", "laboratory", "science")
3. Click on an image
4. Right-click on the image and select "Copy Image Address"
5. Paste the URL in the admin form

### Method 2: Upload to ImgBB
1. Go to https://imgbb.com/
2. Click "Start uploading"
3. Upload your image
4. Copy the "Direct link" URL
5. Paste in the admin form

### Method 3: Use Placeholder Images (For Testing)
```
https://via.placeholder.com/800x600.png?text=Project+Image
https://via.placeholder.com/800x600.png?text=Event+Photo
https://via.placeholder.com/800x600.png?text=Gallery+Image
```
